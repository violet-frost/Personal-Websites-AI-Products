# 李泫邑 · AI 产品作品集

基于 React + Vite 的个人作品集基础版本，内容整理自个人简历。项目视觉为概念示意图，后续可替换为真实作品截图与完整案例。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址（默认 `http://localhost:5173`）。

## 构建预览

```bash
npm run build
npm run preview
```

## 修改内容

- 页面文案与项目数据：`src/App.jsx`
- 颜色、排版与布局：`src/styles.css`
- 个人照片：`public/portrait.jpeg`

网站包含全屏首页、个人经历、三个精选项目、个人优势和整屏联系页。联系按钮使用简历中的邮箱与电话。
